# CircuitLM 0.5

Run `python training/train.py` to fit the committed model from scratch. The 326 authored descriptions in `corpus_v1.json` cover eleven circuit intents and an unsupported class. The model is multinomial naive Bayes with equal class priors and additive smoothing of 0.1. It uses no external inference API or pretrained weights.

The Studio's local parser classifies prompts and checks them against reviewed requests before returning deterministic reference netlists. The temperature motor, Mega light sensor, Mega light sensor with a separately powered servo, and Schmitt inverter are available in local mode. Version 0.3 adds the image-derived AT89C51 and LM016L display subsystem, with a long reviewed prompt and a datasheet-backed physical pin map. Version 0.4 adds a reviewed NE555P astable timer. Version 0.5 adds the AT89C51, LM35 and ADC0804 acquisition subsystem from the temperature-controller reference. Local mode also accepts complete pin-level prose through a deterministic parser. Unsupported clauses produce a clarification instead of being dropped; this path does not use classifier weights to invent components, values or wiring.

`evaluation.json` preserves eight historical authored classification cases. The frontend benchmark also exercises reviewed aliases and a request with an additional unsupported constraint. These checks measure classification and the API's acceptance boundary on authored examples. See [TESTING.md](../TESTING.md) for separate routing results and coverage limits.
