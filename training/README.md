 # CircuitLM-0.1 experimental baseline

Train with `python training/train.py`. The committed weights were fitted from 40 original authored examples using multinomial naive Bayes with Laplace smoothing and equal class priors. Eight authored holdout prompts classified correctly; this is not a statistically robust or independent benchmark. No separate validation set yet. The API only accepts reviewed aliases and uses deterministic existing netlist templates. It rejects other requests and conversational revisions. No external inference service is used. POST /v2/draft with parser=local, prompt='Arduino Uno with a 16x2 LCD', and X-API-Key when CIRCUIT_API_KEY is set. V1 remains explicit parameters only. Authentication is optional unless configured; not production ready. Main is unchanged. Existing README and OpenAPI snapshot describe the older release and require synchronization. Physical correctness, simulation and general netlist generation remain unverified.
